Dolucky no A.League Soccer - English translation v{version}
==========================================================

Unofficial fan translation of "Dolucky no A.League Soccer" (Imagineer / Zoom, 1994, Super Famicom).
This archive holds a patch only. No ROM is included; pre-patched ROMs are not distributed.

What is translated
- Intro story (attract mode), team and character profile cards, ending quotes, the ending message,
  the Japanese "true ending" staff roll with all its jokes, player names on the match HUD,
  the hidden Bonus Mode and Debug Mode menus, and the Japanese title subtitle on the title screen.
- Everything else (menus, HUD, team names) was already English in the original game.
- Lowercase letters were added to the game's font.

Applying the patch
- Base ROM: Dolucky no A.League Soccer (Japan).sfc (No-Intro), headerless, {size} bytes
    CRC32  {crc}
    MD5    {md5}
    SHA-1  {sha1}
- Patch with Flips, Floating IPS, beat or RomPatcher.js (BPS format).
- Patched ROM (2 MB, the patch expands it): CRC32 {pcrc}, SHA-1 {psha1}

Notes
- Tested in MesenCE 2.2.1. Start from a cold boot (no savestates from the Japanese ROM).
- Bonus Mode: at the title/mode select enter Up Left Down Right B Right Down Left Up Y Left Right Up Down Y
  Select Start, then choose OPTION.
- The Debug Mode menu exists in the ROM but the game never opens it; it is translated anyway.

Known issues
- None known. The English staff names follow the game's own English staff roll.
