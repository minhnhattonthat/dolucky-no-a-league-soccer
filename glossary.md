# Glossary - Dolucky no A.League Soccer (SNES, 1994, Imagineer / Zoom)

Binding for every translator and reviewer. Agents propose additions in reports; only the controller edits this file.

## Rulings (BATCH_BRIEF, pre-approved, 2026-10-15)
- Honorifics: dropped, conveyed through register. Name order: given name first (Western).
- Romanisation: the game's own English graphics first (team names on select screens, credits roll), else Hepburn.
- Credits: translated to English. Staff names as in the game's own English roll (TAKAYUKI KAMIKURA etc.).
- Register: light, jokey, self-aware 1994 game humour; animals talk like a sports team. Keep the jokes.
- Abbreviations: none. Full names and terms; the engine was widened instead (see limits in tools/textdefs.py).
- Case: mixed case (lowercase was added to the font). Credits job titles may stay UPPERCASE like the EN roll.

## Style rules
- 「」 -> "..." ; ・・・ / ・・ -> "..." ; ！！ -> "!!" ; ？ -> "?" ; ー in speech -> stretch the word ("Whaaat").
- Only ASCII the font has: letters, digits, space ! " # $ % & ' ( ) * + , - . / : ; < = > ? @ [ ] ^ _ { | }
  No `[XX]` sequences (hex escape in the encoder).
- どうぶつ = animals; どうぶつさっかー = "animal soccer"; Aりーぐ = "A-League" (the game's spoof of Japan's J.League).
- The intro spoofs the earlier game "Dolucky no Kusayakiu" (1993, sandlot baseball): どうぶつやきう = "animal baseball".
